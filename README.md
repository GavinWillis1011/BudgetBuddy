# College Budget Buddy

A student-focused budgeting tool designed to help users manage their money, find affordable meals, and track savings goals.

## Features

- **Budget Tracker:** Add and manage income and expenses.
- **Dark Mode:** Switch between light and dark themes.
- **Cheap Eats:** Search recipes using TheMealDB API.
- **Weekly Meal Planner:** Add recipes to a weekly meal plan.
- **Nearby Food Map:** Find nearby restaurants and cafes using OpenStreetMap and Overpass API.
- **Savings Goals:** Create savings goals, track deposits, and monitor progress.
- **Local Storage:** Saves user data in the browser.

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap 5
- Leaflet
- OpenStreetMap
- Overpass API
- TheMealDB API

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Allow location access on the Cheap Eats page to use the nearby food map.
